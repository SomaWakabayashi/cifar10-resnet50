# CIFAR-10 画像分類: 最適化 ResNet50 プロジェクト

本プロジェクトでは、標準的な ResNet50 モデルを CIFAR-10 データセット（32x32ピクセル）に適合するよう最適化し、スクラッチ学習で **94.39%** の検証精度を達成しました。

## 実験結果サマリ
段階的な施策導入による精度の推移は以下の通りです。

| ステップ | 施策の概要 | 検証精度 (Val Acc) | 改善のポイント |
| :--- | :--- | :---: | :--- |
| **Baseline** | 標準 ResNet50 (7x7 conv1) | 43.95% | スタート地点 |
| **Step 1** | 正則化 (LS, WD) の導入 | 86.32% | 過学習の抑制 |
| **Step 2** | **アーキテクチャの CIFAR 最適化** | **92.80%** | **低解像度情報の保護** |
| **Final** | **高度な拡張 + 100エポック学習** | **94.39%** | **汎化性能の極大化** |

## 主要な改善施策

### 1. アーキテクチャの最適化
標準の ResNet50 は ImageNet（224x224）向けに設計されており、初層の 7x7 Conv と MaxPool 層によって、入力直後に画像サイズを 1/4 まで縮小させます。32x32 の CIFAR-10 ではこの過程で重要な空間情報が失われるため、以下の最適化を行いました。
- **初層の変更**: 7x7 Conv (stride=2) → 3x3 Conv (stride=1)
- **MaxPool の削除**: 入力直後の解像度を維持し、特徴抽出能力を向上。
- **効果**: この構造変更のみで、精度が +6.48% (86.32% → 92.80%) 向上しました。

### 2. データ拡張と正則化
過学習を抑え、未知データに対する汎化性能を高めるために以下の手法を統合しました。
- **高度な拡張**: Mixup (alpha=1.0), RandAugment, Random Erasing
- **強力な正則化**: Weight Decay (1e-3), Label Smoothing (0.1)
- **学習戦略**: 100エポックの長期学習を Cosine Annealing スケジューラで制御。

## 使い方

pip install -r requirements.txt

python train.py --exp_name "resnet50_final_100e" --epochs 100

### 推論の実行
python predict.py --image path/to/your_image.png --model runs/resnet50_cifar10_pure_100e/model.pth

## 📈 分析と考察

### 学習曲線の推移と正則化の効果
Mixup や RandAugment を採用したモデルは、序盤の収束は緩やかですが、学習率が低下する後半戦（80エポック以降）において精度が急上昇する挙動を示しました。これは、強力な正則化によって「データの暗記（過学習）」を阻害されたモデルが、学習率の低下と共に「本質的な特徴」を捉え始めた結果であると考えられます。

### 誤分類分析と今後の課題
混同行列の解析から、「犬（dog）」と「猫（cat）」の識別において最も誤分類が発生していることが判明しました。これは CIFAR-10 の低解像度において、両者のテクスチャが酷似していることが原因です。
今後の改善案：
1. CutMix の導入: 物体の一部を入れ替えることで、形状への注目度を高める。
2. TTA (Test Time Augmentation): 推論時に複数回の拡張を行い平均をとる。
